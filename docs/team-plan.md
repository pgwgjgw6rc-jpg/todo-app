## 📝 Команды Git (шпаргалка)

```bash
# Клонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/task-planner-team.git

# Создать ветку
git checkout -b название-ветки

# Посмотреть статус
git status

git add .

# Сделать коммит
git commit -m "Сообщение"

# Отправить на GitHub
git push origin название-ветки

# Получить изменения
git pull origin main

# Слить ветку (находясь в main)
git merge название-ветки
